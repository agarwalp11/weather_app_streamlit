# Weather App

A simple Python command-line application that uses the OpenWeather API to retrieve current weather information for a city entered by the user.

## Features

- Search weather by city
- Displays temperature in Celsius
- Displays humidity
- Displays weather description
- Displays the "feels like" temperature

## Setup
1. Install the required packages:

install requests python-dotenv


2. Create a `.env` file in the project folder and add your OpenWeather API key:

OPENWEATHER_API_KEY=your_api_key_here

3. Run the program:

python get_weather.py


4. Enter a city when prompted:


Enter city: Pittsburgh

The current weather information for the city will be displayed in the terminal.
